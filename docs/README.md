# Capstone Documentation

This folder collects the written evidence for the App Track rubric.

## Documents

- [Research Question](research-question.md)
  Defines the problem, target users, and measurable project goal.
- [App Design](app-design.md)
  Documents personas, user journey, interface decisions, accessibility, responsive design, and style choices.
- [App Analysis](app-analysis.md)
  Captures manual testing, user feedback, performance observations, errors, and iteration notes.
- [Data Dictionary](data-dictionary.md)
  Explains the relational schema, important fields, constraints, indexes, growth considerations, and backup/recovery approach.
- [Model Documentation](model-documentation.md)
  Explains the notebook pipeline, LightGBM model, features, target, tuning, evaluation metrics, and limitations.
- [Poster Plan](poster-plan.md)
  Outlines the poster structure, visuals, screenshots, architecture diagram, and main talking points.

## How To Use These Docs

Each document starts with a draft based on the current Driver Earnings Navigator app. Sections marked `TODO` should be filled in with project-specific evidence, measurements, screenshots, or feedback before final submission.
